# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository. Include affected versions,
impact, reproduction steps, and any suggested mitigation. Do not include real
credentials, private notes, personal data, or production host details.

Maintainers will acknowledge a complete report as soon as practical, validate
the impact, and coordinate disclosure after a fix is available.

## Deployment boundary

Personal Intelligence Hub is private by default. Operators are responsible for
keeping the application and its APIs on a private network, supplying secrets
outside Git, and reviewing generated configuration before deployment.
